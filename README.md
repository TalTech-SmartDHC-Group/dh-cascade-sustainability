# District Heating Cascade Sustainability Framework

A research framework for modelling multi-level district heating energy cascades and assessing sustainability across seven dimensions:

- Thermodynamic
- Environmental
- Economic
- Technical
- Flexibility
- Resilience
- Policy

The associated research considers Estonia as a national-scale case study, using ETHOS.FINE for energy system optimisation.
